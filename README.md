
# Bill Splitter Calculator 💸

A simple Python mini project that calculates:

- Total restaurant bill
- 25% tip amount
- Total bill including tip
- Bill per person
- Final amount each friend pays (rounded to 2 decimal places)

## 📌 Features

- Uses arithmetic operators
- Demonstrates the `+=` operator
- Uses the `round()` function
- Splits the bill equally among friends

## 🐍 Code Concepts Used

- Variables
- Addition and division
- Compound assignment (`+=`)
- `print()` statements
- `round()`

## ▶️ Example Output

```text
Total bill so far: 198.83
Tip amount: 49.7075
Total with tip: 248.5375
Bill per person: 62.134375
Each person pays: 62.13
````

## 📂 File

* `bill_splitter.py`

## 🚀 How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python bill_splitter.py
```

## 🎯 Purpose

This beginner-friendly project was created to practice Python fundamentals and build confidence with real-world calculations.
